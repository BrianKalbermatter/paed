# Bienvenido a PseudoGames

Aprendé algoritmos escribiendo pseudocódigo real.
Cada nivel tiene un problema para resolver. Escribís tu solución, la ejecutás, y avanzás.

---

## La estructura de todo algoritmo

Todo algoritmo tiene exactamente esta forma:

```
ACCION nombre_del_algoritmo
  AMBIENTE
    // Variables que vas a usar
    variable : TIPO;

  PROCESO
    // Los pasos para resolver el problema
    ESCRIBIR("Hola mundo");
FIN_ACCION
```

**AMBIENTE** → declarás las variables (espacio en memoria).
**PROCESO** → escribís los pasos.

---

## Tipos de datos básicos

| Tipo      | Ejemplo         |
|-----------|-----------------|
| ENTERO    | edad := 25      |
| REAL      | precio := 9.99  |
| CARACTER  | letra := 'A'    |
| BOOLEANO  | activo := V     |

---

## Las dos instrucciones esenciales

```
LEER(variable);          // recibe un valor del usuario
ESCRIBIR("texto");       // muestra algo en pantalla
```
